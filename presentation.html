5. Model Architecture Deep Dive

  • EfficientNet-B0 Backbone:
    • Uses Mobile Inverted Bottleneck (MBConv) blocks.
    • Transfer learning from ImageNet (frozen backbone).
  • Custom Classification Head:
    • Dropout (p=0.3) for regularization.
    • Linear Layer mapping 1280 features to 2 classes.
  • Fine-tuning Strategy: Train head first, then unfreeze top blocks with lower learning rate.
(Conv2d) 3x224x224

(Linear) 1280 → 2 (Real/Fake)

6. Dataset & Preprocessing

  • Datasets: Compiled from FaceForensics++, Celeb-DF, and Real-vs-Fake.
  • Data Leakage Prevention: Train/Val/Test split done strictly at the video level.
  • Imbalance Handling: Applied WeightedRandomSampler to ensure equal representation of Real and Fake batches during training.
  • Augmentations:
    • Random Horizontal Flip
    • Random Rotation (±10°)
    • Color Jitter (Brightness/Contrast ±20%)

7. Training Pipeline

  • Optimizer: AdamW (Weight Decay)
  • Learning Rate: 0.001 with Scheduler
  • Loss Function: CrossEntropyLoss
  • Early Stopping: Monitor Validation Loss
  • Hardware Auto-detect: CUDA → MPS → CPU

9. Explainability with Grad-CAM

What is Grad-CAM?

Gradient-weighted Class Activation Mapping. It uses the gradients flowing into the final convolutional layer to produce a localization map highlighting important regions.

Why it matters:

  • Provides transparency & builds user trust.
  • Highlights blending artifacts usually found around the eyes, mouth, and face boundaries.
